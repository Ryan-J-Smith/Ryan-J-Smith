I build AI systems for knowledge work and decision support. Ex-McKinsey / QuantumBlack, PhD in neural decoding, currently a solo founder.

## About the green wall

Since May 2025 I've been building an AI-native platform for structured, multi-perspective strategic decision support. The codebase is private; the contribution graph is what that looks like from the outside.

A few things about how it's built, since that's the part I'm happy to talk about in detail:

- Domain-driven modular monolith, ~70 packages, Python and TypeScript, designed from day one to be as operable by an AI agent as by a person.
- Built with a formalized AI-assisted development process: written specs, independent spec review, dry-run planning before implementation, enforced commit gates, and quantified after-action reports. Roughly two-thirds of commits are co-authored with Claude, with model versions recorded in the trailer.
- Multiple parallel agent instances, each owning a branch, coordinated by the planning layer rather than by hope.

If you're evaluating the work, I can walk through the architecture and the process on a call; that's a better read than a repo browse would be anyway.
